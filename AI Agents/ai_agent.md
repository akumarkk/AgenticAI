##### AI Agent

AI Agent = {
    Specific prompt,
    LLM,
    set of tools
}

The agent represents
- Perception module
- Reasoning core
- Action orchestration
- learning subsystem

key terms were originated from *Robotics and cognitive science*
seperation of the module, required because if agent fails, we can instantly troubleshoot if agent
- perception error (misread the input)
- reasoning error (made a bad plan)
- action error (botched a tool call)


NOTE : AI Agent : orchestration system(LangGraph, Autogen, custom AI frameworks)
