# Langflow Packages Summary & Categorization

This document provides a categorized breakdown of the packages installed with Langflow, outlining their primary functional domains within the AI and Python ecosystem.

| Category | Key Examples | Primary Function |
| :--- | :--- | :--- |
| **Core Frameworks & Orchestration** | `langchain`, `langgraph`, `langflow`, `lfx`, `smolagents` | Visual wiring, agent logic, and multi-agent workflow orchestration. |
| **LLM Providers & Models** | `openai`, `anthropic`, `cohere`, `google-genai`, `ollama` | Connecting to proprietary cloud models and local runtime endpoints. |
| **Vector Databases & Storage** | `chroma`, `qdrant-client`, `weaviate-client`, `duckdb`, `astrapy` | Storing text embeddings for semantic search and RAG retrieval. |
| **Telemetry & Observability** | `langfuse`, `arize-phoenix-otel`, `opik`, `opentelemetry-*` | Tracing, logging, debugging agent actions, and monitoring token metrics. |
| **Document Processing & Data** | `docling`, `pypdf`, `python-docx`, `pandas`, `tiktoken` | Parsing files, splitting text chunks, and managing data arrays. |
| **Networking, Cloud & APIs** | `fastapi`, `boto3`, `google-auth`, `azure-core`, `httpx` | Powering the web server endpoints and interacting with cloud providers. |
