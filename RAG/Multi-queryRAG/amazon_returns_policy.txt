Amazon Return Policy Overview:
Standard Return Window: Most new, unopened items sold or fulfilled by Amazon can be returned within 30 days of delivery.

Category Exceptions:
- Apple Products: 15-day return window.
- Amazon Renewed Items: 90-day return window (or up to 365 days for Renewed Premium).
- Baby Registry Items: 365 days from delivery.
- Extended Holiday Return Window: Items purchased between November 1 and December 31 can typically be returned until January 31.

Non-Returnable Items:
- Downloadable software, gift cards, grocery products, live plants, and customized/personalized products.

Return Shipping & Locations:
- Free returns are available for eligible items drop-off locations including The UPS Store, Kohl's, and Whole Foods Market.
- For QR code drop-offs, no original box or printer is required.

Restocking Fees:
- Restocking fees may apply if items are returned opened, missing parts, damaged, or outside the allowed return window.
